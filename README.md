# GameBoss Q8 — المتجر الجديد

متجر إكسسوارات ألعاب سريع وشبابي (تصميم فاخر بأسلوب آبل، عربي RTL) — نسخة جاهزة للعرض والنشر.

## المحتويات
- `index.html` — واجهة المتجر (189 منتج حقيقي · 12 قسم · سلة · شراء سريع).
- `admin/index.html` — لوحة التحكم (إحصائيات + إضافة/تعديل/حذف منتجات + رفع صور — تجريبية بالمتصفح).
- `catalog.json` — الكتالوج الكامل (مستخرج من WooCommerce).

## معاينة محلية
افتح `index.html` بأي متصفح. صور المنتجات تُحمّل من `gamebossq8.com`.

## النشر السريع (بدون كود)
اسحب مجلد المشروع كامل إلى:
- **Netlify Drop**: https://app.netlify.com/drop
- أو **Vercel**: https://vercel.com/new

خلال ثوانٍ يصير عندك رابط مباشر، والمتجر يفتح على `/` ولوحة التحكم على `/admin`.

## الرفع على GitHub
1. أنشئ مستودع جديد فارغ باسم `gamebossq8-store`.
2. ارفع كل الملفات (Upload files / سحب وإفلات).
3. (اختياري) فعّل GitHub Pages من Settings → Pages.

## ملاحظات
- الأسعار والأقسام والصور حقيقية من متجركم الحالي.
- هذه نسخة عرض ثابتة (Front-end). النسخة الإنتاجية الكاملة (Next.js + قاعدة بيانات + دفع KNET + حفظ الطلبات) هي الخطوة التالية.
